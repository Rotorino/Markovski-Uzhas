# Отчет по лабораторной работе №1

## Цель

Освоить базовые средства Visual Prolog: консольный ввод-вывод, строки, математические функции, генерацию случайных чисел и запись в файл.

## Алгоритм

Программа запрашивает строку и три целых числа. Для строки вычисляется хэш и выделяются две половины; для чисел вычисляется `max(A,B,C) - min(B,C)`. Затем введенное число складывается со случайным числом из диапазона `[0, N)`. Все полученные значения сохраняются в текстовый ANSI-файл.

См. `tests/manual-tests.md`.

## Вывод

Реализованы операции со строками, целыми числами, библиотекой `math` и выходным файловым потоком.
