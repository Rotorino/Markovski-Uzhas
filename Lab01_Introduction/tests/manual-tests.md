# Ручные тесты

| Тест | Ввод | Ожидаемый результат |
| --- | --- | --- |
| Строка четной длины | `abcd` | Половины: `ab` и `cd` |
| Строка нечетной длины | `abcde` | Половины: `ab` и `cde` |
| Выражение | `A=2, B=7, C=4` | `7 - 4 = 3` |
| Случайное число | число `10` | Второе слагаемое находится в диапазоне от 0 до 9 |
| Запись файла | любой корректный ввод | Создается `Lab01_Task05_ANSI.txt` с результатами |
